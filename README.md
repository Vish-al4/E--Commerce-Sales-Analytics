# E--Commerce-Sales-Analytics
E-Commerce Sales Analysis and Dashboard using Power BI
🛒 E-Commerce Sales Analytics Dashboard

📊 Project Overview

This project analyzes E-Commerce sales data and presents key business insights using Power BI.

🎯 Objectives

- Analyze total sales and orders
- Identify top-performing categories and products
- Analyze city-wise sales
- Understand payment mode performance
- Track sales trends over time

🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- SQL
- Power BI
- Data Visualization

📈 Dashboard Features

- Total Sales KPI
- Total Orders KPI
- Total Quantity Sold KPI
- Category-wise Sales
- Product-wise Sales
- City-wise Sales
- Payment Mode-wise Sales
- Sales Trend by Order Date
